# 🛒 E-commerce Frontend

Une application e-commerce moderne développée avec React, Vite et Tailwind CSS.

## 🔗 Démo en ligne

[Cliquez ici pour essayer l'application](https://ecommerce-frontend-two-sigma.vercel.app)

## ✨ Fonctionnalités

- ✅ Afficher les produits (grille responsive)
- ✅ Voir le détail d'un produit
- ✅ Ajouter au panier
- ✅ Gérer le panier (supprimer, total)
- ✅ Filtrer par catégorie (badges)
- ✅ Page admin (ajouter, modifier, supprimer des produits)
- ✅ 12 produits + 3 catégories
- ✅ Design responsive (mobile-friendly)
- ✅ Animations et transitions
- ✅ Navigation entre les pages (React Router)

## 🛠️ Technologies utilisées

- **React 19** : Bibliothèque UI
- **Vite** : Outil de build
- **Tailwind CSS** : Framework CSS
- **React Router** : Navigation entre les pages
- **Axios** : Requêtes HTTP vers le backend
- **Vercel** : Déploiement
